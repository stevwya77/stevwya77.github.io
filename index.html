A2

Nand2Tetris ↗

A computer from first principles · 2025

nand2tetris
Watch full size ↗

A working computer built up from a single NAND gate, following The Elements of Computing Systems. The hardware is written in HDL, and the assembler for it is written in Rust.

  • Built the chips in HDL from NAND up: logic gates and multiplexers, adders and the ALU, registers and RAM, then the Hack CPU and computer.
  • Wrote a two-pass assembler in Rust. The first pass records label addresses, the second translates each instruction into 16-bit machine code and allocates variables from RAM address 16.
  • Rust
  • HDL
  • Hack assembly
A3

Arcade Engine ↗

2D game engine in C++20 · 2026

arcade
Watch full size ↗

A small 2D game engine in C++20 on SFML 3. It runs the window, frame loop, input, audio, saves, and GUI, so a game only has to supply its scenes. Bounce, the first game built on it, shows it in action.

  • Built action-based input that binds keys, mouse buttons, and gamepad buttons or stick axes to the same game action, with Xbox and PlayStation layouts mapped to shared button names.
  • Wrote a post-processing chain that renders each frame off-screen and runs it through GLSL shaders: bloom (downsample, two-pass Gaussian blur, additive blend) and a CRT monitor look.
  • Added scenes with queued switching, a pause overlay, JSON config and saves, and managers for resources, audio, screenshots, and timing.
  • C++20
  • SFML 3
  • GLSL
  • TGUI
  • CMake
